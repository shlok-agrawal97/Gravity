# Logistics Website – Responsive Web Design

Developed a fully responsive and modern logistics website using HTML5, CSS3, and Bootstrap 5, designed to provide a seamless and user-friendly experience across desktop, tablet, and mobile devices. The project focuses on creating a professional dark-themed interface with smooth animations, interactive components, and an intuitive layout to represent a logistics and transportation business.

The website features a visually engaging hero section that highlights the company's services and establishes a strong first impression. Animated statistics cards showcase important business metrics, while an interactive services carousel presents different logistics and shipping solutions in an attractive and organized manner.

A dedicated process timeline section illustrates the different stages of the logistics workflow through an alternating layout, making the information easy to understand and visually appealing. The website also includes a shipping rate calculator with a hover-reveal form, allowing users to interact with the interface and explore shipping-related functionality.

A sign-in modal has been integrated to enhance the user interface and demonstrate authentication-related design elements. The detailed footer includes essential navigation links, contact information, and app download badges, providing a complete and professional website structure.

Special attention was given to responsive design, clean code structure, consistent styling, smooth hover transitions, and modern UI principles. Bootstrap 5 was used to create a flexible layout, while custom CSS was implemented to achieve the desired dark theme, animations, and interactive visual effects.

### Key Features
- Fully responsive design for all screen sizes
- Modern dark-themed user interface
- Animated statistics cards
- Interactive services carousel
- Alternating logistics process timeline
- Shipping rate calculator with hover-reveal form
- Sign-in modal interface
- Detailed footer with app download badges
- Smooth hover effects and transitions
- Clean and structured frontend development

### Technologies Used
- HTML5
- CSS3
- Bootstrap 5

### Project Objective
The main objective of this project was to strengthen frontend development skills by building a complete, responsive, and visually engaging logistics website while applying modern web design principles and interactive UI components.
